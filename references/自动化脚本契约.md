# 自动化脚本契约

## 职责

规定未来 MyNovel Skill 内置脚本的文件名、用途、调用方式和输出用途。

## 脚本目录

通用脚本放在：

```text
C:\Users\Lenovo\.claude\skills\MyNovel\scripts\
```

单本小说专属导出脚本仍放在小说项目目录，例如 `convert_to_epub.py`。

## 已实现脚本

- `小说质检.py`：字数统计（省略号加权口径）、AI味三梯队词、禁用词、关键时间锚候选、能力解锁候选扫描。
- `count_chars.py`：审查字数统计 CLI，口径与 `小说质检.py` 一致。

## 调用原则

- 脚本是普通本地命令行工具，不依赖隐藏 hook。
- Claude Code、Codex 和子 agent 都通过 shell 调用脚本。
- 脚本存在且适用时，优先使用脚本输出作为证据。
- 脚本不存在时，不临时创建替代脚本；在报告中注明未使用脚本。
- 脚本输出可写入审查报告、验证结论和修复记录。
- 脚本负责输出事实和证据，不负责判断模糊用户意图。模糊定位、取舍和追问仍由 Agent 完成。
- 默认输出 JSON；需要可读报告时可加 `--format markdown`。

## 命令契约

Windows 调用说明：如果 `python` 指向 Windows Store 占位程序或 python 不可用，改用 `py -3` 调用同一脚本。报告中记录实际使用的命令即可。

### 小说质检.py

用途：字数、AI味三梯队、禁用词、时间锚候选、能力/资源候选扫描。

```powershell
python C:\Users\Lenovo\.claude\skills\MyNovel\scripts\小说质检.py lint --file D:\ai小说\小说\都市-大医无双\正文\第001章_绝境.md
py -3 C:\Users\Lenovo\.claude\skills\MyNovel\scripts\小说质检.py lint --file D:\ai小说\小说\都市-大医无双\正文\第001章_绝境.md
```

关键输出：`word_count`（`unit: review_char`）、`ai_flavor`、`forbidden_words`、`time_anchor_candidates`、`ability_candidates`。

字数统计口径（审查口径）：非空白字符 + 省略号加权（`……` 算 6、`…` 算 3）。由 `公共工具.count_review_chars` 实现。

### count_chars.py

用途：审查字数统计 CLI，口径与 `小说质检.py` 一致。支持文件和目录。

```powershell
python C:\Users\Lenovo\.claude\skills\MyNovel\scripts\count_chars.py D:\ai小说\小说\都市-大医无双\正文\第001章_绝境.md
python C:\Users\Lenovo\.claude\skills\MyNovel\scripts\count_chars.py D:\ai小说\小说\都市-大医无双\正文\
py -3 C:\Users\Lenovo\.claude\skills\MyNovel\scripts\count_chars.py D:\ai小说\小说\都市-大医无双\正文\第001章_绝境.md
```

## 审查证据写入规则

- 审查报告中引用脚本结果时，写明脚本名、命令目的和关键 JSON 字段。
- `小说质检.py` 的输出是字数、AI味和禁用词的优先证据。
- 未传入 `--forbidden-words` 时，脚本必须输出 `FORBIDDEN_WORDS_NOT_CONFIGURED` 警告；空匹配不能解释为禁用词检查通过。
