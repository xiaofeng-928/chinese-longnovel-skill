# 自动化脚本契约

## 职责

规定未来 MyNovel Skill 内置脚本的文件名、用途、调用方式和输出用途。

## 脚本目录

通用脚本放在：

```text
C:\Users\Lenovo\.claude\skills\MyNovel\scripts\
```

单本小说专属导出脚本仍放在小说项目目录，例如 `convert_to_epub.py`。

## v1.2 已实现脚本

- `小说质检.py`：字数统计、AI味词、禁用词、关键时间锚、能力解锁扫描。
- `小说文件.py`：定位项目文件、计算 50 章归档路径、检测同章多文件。
- `小说锚点.py`：检查稳定锚点、替换目标锚点块。
- `小说上下文.py`：确定性组装上下文文件列表。

## 调用原则

- 脚本是普通本地命令行工具，不依赖隐藏 hook。
- Claude Code、Codex 和子 agent 都通过 shell 调用脚本。
- 脚本存在且适用时，优先使用脚本输出作为证据。
- 脚本不存在时，不临时创建替代脚本；在报告中注明未使用脚本。
- 脚本输出可写入审查报告、验证结论和修复记录。
- 脚本负责输出事实和证据，不负责判断模糊用户意图。模糊定位、取舍和追问仍由 Agent 完成。
- 默认输出 JSON；需要可读报告时可加 `--format markdown`。

## 命令契约

### 小说文件.py

用途：项目扫描、章节状态、50 章归档路径计算。

```powershell
python C:\Users\Lenovo\.claude\skills\MyNovel\scripts\小说文件.py scan-projects --root D:\ai小说 --query 大医无双
python C:\Users\Lenovo\.claude\skills\MyNovel\scripts\小说文件.py chapter-status --project D:\ai小说\小说\都市-大医无双 --range 1-30
python C:\Users\Lenovo\.claude\skills\MyNovel\scripts\小说文件.py archive-path --project D:\ai小说\小说\都市-大医无双 --chapter 61 --type summary
```

关键输出：`projects`、`match_score`、`existing_chapters`、`missing_chapters`、`duplicate_chapters`、`archive.path`。

### 小说质检.py

用途：字数、AI味三梯队、禁用词、时间锚候选、能力/资源候选扫描。

```powershell
python C:\Users\Lenovo\.claude\skills\MyNovel\scripts\小说质检.py lint --file D:\ai小说\小说\都市-大医无双\正文\第001章_绝境.md
```

关键输出：`word_count`、`ai_flavor`、`forbidden_words`、`time_anchor_candidates`、`ability_candidates`。

字数统计口径：所有非空白字符都计 1；中文、标点、数字、英文字母都计数，空格、制表符和换行不计数。

### 小说锚点.py

用途：检查和替换归档文件中的单章稳定锚点块。

```powershell
python C:\Users\Lenovo\.claude\skills\MyNovel\scripts\小说锚点.py check --file D:\ai小说\小说\都市-大医无双\章节总结\章节总结_第1-50章.md --chapter 22 --kind summary
python C:\Users\Lenovo\.claude\skills\MyNovel\scripts\小说锚点.py replace --file D:\ai小说\小说\都市-大医无双\章节总结\章节总结_第1-50章.md --chapter 22 --kind summary --content-file D:\temp\summary.md --dry-run
```

关键输出：`exists`、`missing`、`duplicate`、`start_count`、`end_count`、`changed`、`dry_run`。替换前必须先 dry-run；锚点重复时不得写入。

### 小说上下文.py

用途：为草稿生成、审查、修复输出确定性上下文清单。

```powershell
python C:\Users\Lenovo\.claude\skills\MyNovel\scripts\小说上下文.py build --project D:\ai小说\小说\都市-大医无双 --chapter 23 --mode review
```

关键输出：`novel_config`、`recent_chapters`、`chapter_summaries`、`outline`、`stage_summaries`、`foreshadowing_hints`。

## 审查证据写入规则

- 审查报告中引用脚本结果时，写明脚本名、命令目的和关键 JSON 字段。
- `小说质检.py` 的输出是字数、AI味和禁用词的优先证据。
- `小说上下文.py` 的输出用于证明本轮读取了哪些上下文文件和范围。
- `小说文件.py` 的输出用于证明项目定位、章节缺失和同章多文件情况。
- `小说锚点.py` 的输出用于证明写回归档时只替换目标锚点块。
