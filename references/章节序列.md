# 有效章节序列

## 目的

记录正文创作的实际阅读顺序，解决插入章节、支线章节和主线章节混排时不能按章节数字计算上下文的问题。

## 节点字段

| 字段 | 取值 |
|---|---|
| 节点编号 | `第49章`、`第49(1)章` 等现有命名 |
| 类型 | 主线、手动插入、支线 |
| 主线锚点 | 是/否 |
| 正文状态 | 未开始、已写出未审查、已审查、已修复、废弃 |
| 细纲状态 | 已整理的正式细纲 |

只有正文文件存在且节点未标记为废弃时，节点才是有效正文节点。已写出但未审查的正文仍然有效。

## 上下文读取规则

对当前节点：

1. 在序列中定位当前节点。
2. 向前读取最近 3 个有效节点的正文和对应章节总结。
3. 再向前读取最近 1 个“主线锚点”为“是”的有效节点；若已经在最近 3 个节点内，不重复读取。
4. 读取最近 20 个有效节点的章节总结，并去重。
5. 读取当前节点的正式细纲，以及序列中后续 2 个主线节点的边界细纲。

例如写第50章时，若前序为第49(1)、第49(2)、第49(3)，且最近主线锚点是第48章，则正文上下文为这 3 个插入节点加第48章，而不是按数字回退计算。

“支线”只描述内容性质，不自动排除节点；是否作为主线锚点由字段单独决定。
