# 短篇拆书与原创重组

当用户选择一篇或多篇范文作为创作参考时，先完成拆书，再生成新作大纲。拆书只处理用户提供、明确授权或确认具有合法使用权的正文；只有标题、简介、链接或“待导入”文件不能进行全文拆书。

## 一、拆书输出

将每篇选定范文完整读完，使用代称和标签提炼，不抄录原文句子、专名、人物关系或具体场景。

拆完单篇范文后，先把以下内容写回该范文 Markdown 的“精读笔记”区，作为范文库长期资产。若正文已经补齐而精读笔记仍为“待填写”，必须先完成精读笔记，不能直接跳到新作大纲。

### 1. 主线压缩

剥离支线，只保留由核心主角驱动的绝对主线因果，用一段连续的“起—承—转—合”复合句呈现。主角统一写作 `【男一】` 或 `【女一】`，对手写作 `【反派】`，不在此阶段填入新作姓名。

### 2. 关键事件链

按故事发生顺序列出 10-15 个核心事件。每个事件使用“`【核心主角】+动作+结果`”的一句话结构，必须能看出因果推进，不写氛围、闲聊或无结果的场面。

### 3. 可复用套路模板

提炼 3-5 个脱离专名后仍成立的通用句式，例如：

> 当 `【核心主角】` 在 `【公开场合】` 遭遇 `【对手】` 的 `【身份/资源】` 打压时，选择 `【反常但合理的行动】`，导致 `【公开后果】`。

模板只能描述冲突机制、情绪路径、信息差或反转方式，不得保留原作的独特表达。

### 4. 人设标签

只用代称和标签化词语提炼：

- `【核心主角】`：身份/出身、外在伪装、真实性格、核心欲望、致命弱点、能力、成长弧光；
- `【重要关系角色】`：身份、性格、对主角的起始印象、态度转折点、情感或利益契机、自身目标；
- `【反派】`：身份层次、核心动机、与主角的冲突、标志性失败场景；
- 功能角色：功能和结局，例如协助、阻碍、牺牲、背叛、救赎或提供资源。

## 二、原创重组

拆书完成后，先建立“参考机制清单”，再生成新作，不能把拆书结果当成改名改词的底稿。新作至少重新设计以下五项中的四项：人物与关系、核心冲突、事件因果链、反转机制、结局选择。若五项都高度相同，结论为“应重构”，暂停正文生成。

生成大纲时按当前类型提示词规定的篇幅和节奏组织，至少包含：世界/生活处境钩子、激励事件、核心冲突、第一次高潮、关系或利益转折、低谷/损失、反转与终局、结局回收。具体类型规则以 `<作品类型>/提示词/大纲提示词.md` 为准。

需要用户后续填入的姓名、世界观、势力、地名、系统、法宝、技能、时间节点或称谓，统一使用 Markdown 加粗占位符 `**中文占位符**`；角色仍保留 `【男一】`、`【女一】`、`【反派】` 等代称，并在首次出现时附加加粗姓名占位符。用户确认后再统一替换，不能把占位符混入正文。

## 三、执行顺序与归档

1. 正文补齐后，先更新对应范文文件的正文状态并完成单篇精读笔记。
2. 用户选择范文，将文件名和参考维度写入作品的 `参考素材.txt`。
3. 读取选定范文的正文与精读笔记，生成作品的 `拆书记录.md`，保存本次采用的主线机制、事件结构、套路、人设标签和参考边界。
4. 根据拆书记录与类型大纲规则生成 `大纲.md`，完成原创性闸门检查。
5. 按大纲分章写入 `正文/第001章_<标题>.md` 等正文文件；每章写完复读确认。
6. 用户说“洗稿”或“润色”时，只对用户提供或本人拥有使用权的自有正文执行对应类型的台词润色规则，不对外部范文做近似改写。
7. 正文完成后读取类型审查提示词，生成 `审查报告.md`；审查必须同时对照 `拆书记录.md`、`大纲.md` 与正文，检查是否过度贴近参考机制或出现未授权复用。

范文文件里的精读笔记服务于整个作品类型；具体作品的 `拆书记录.md` 只记录本次选材与重组决策。二者不得互相替代。

拆书记录是参考依据，不是正文硬约束；大纲是短篇合理性检查依据，不得套用长篇的 50 章细纲、阶段总结或黄金三章归档。
