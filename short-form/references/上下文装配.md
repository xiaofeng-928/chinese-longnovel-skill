# 短篇上下文装配

创建项目、生成、续写或审查正文时，按以下顺序读取：

1. 当前作品的 `参考素材.txt`，确认用户选定的范文文件名、选择理由和可参考维度；
2. 作品类型的 `范文参照/范文合集.txt`、`范文参照/类型创作特征.md`，以及 `参考素材.txt` 中逐一列出的 `范文参照/范文/*.md` 的正文与精读笔记；
3. 当前作品的 `拆书记录.md`（使用范文创作时必读）;
4. 当前作品的 `config-novel.md`、`大纲.md`；
5. 当前章前直接相连的正文，以及解决未完冲突所必需的更早正文。

范文正文必须实际存在、具有合法使用来源且精读笔记已经完成。只含标题、链接、“待导入”正文或“待填写”精读笔记的文件不能作为全文范文上下文。范文不设额外 Token 预算，按文件完整读取；但只使用用户选定的文件，避免无关范文污染创作方向。

多篇范文同时使用时，先提炼可复用的抽象创作思路，再为新作设计独立的人物、关系、事件因果、反转和语言。不得将“改写”理解为替换姓名或局部改词。

缺少范文、类型特征或大纲时说明缺失；创建新作时缺少用户选择的可用范文，应先询问是否补充或确认无范文创作。不得把长篇阶段总结、50 章细纲或黄金三章规则引入短篇。
